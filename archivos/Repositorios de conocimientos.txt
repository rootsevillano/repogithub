ESTO ES UNA PUTA MINA DE ORO

Anthropic acaba de compartir el truco más afilado para Claude Code

La idea: dejar que Opus 5.5 escriba el plan como un script, y arremeter con el nuevo Haiku 5.5 en paralelo

Barridos masivos con cero consumo de Opus: el script mantiene el bucle y Opus solo ve el diff final

Solo lanzas Claude Code así:

claude --model opus --effort ultracode

aquí está la división:

→ Opus 5.5 convierte tu objetivo en un script de flujo de trabajo ejecutable
→ Haiku 5.5 arremete contra cada archivo en paralelo a 340 tok/s para extraer candidatos
→ Sonnet 5.5 parchea cada corrección y verifica hallazgos cruzados en su propia copia aislada
→ dejas de quemar contexto de Opus en cientos de transcripciones de agentes

Opus solo aparece en tres momentos:

→ autorizando el script de flujo de trabajo antes de la ejecución
→ leyendo hallazgos verificados después de que termine el arremetimiento
→ firmando antes de que nada se envíe a git

Opus planea · Haiku escanea · Sonnet envía

La ingeniería JEV es el mismo movimiento una capa abajo: los forks que no necesitan pensador (qué archivo, qué herramienta, reintentar o parar) van a JEV en milisegundos, y los grandes modelos solo ven los que se bifurcan

el árbol completo
> Opus 5.5 ejecuta la sesión principal y escribe workflow.js
> pipeline() despliega el nuevo Haiku 5.5 para auditar cada archivo
> parallel() validadores de esquema eliminan falsos positivos en V8
> Sonnet 5.5 parchea cada corrección en un worktree aislado
> verify verifica cruzado todos los diffs antes de reportar
> Opus 5.5 lee solo lo que sobrevivió a la verificación
> JEV enruta micro-forks en milisegundos

pega el árbol y este prompt en Claude Code ↓

"Reconstruye mi setup de Claude Code alrededor de este árbol:
1. Ejecuta la sesión principal en Opus 5.5 con ultracode activado
2. En cada flujo de trabajo, ejecuta etapas de escaneo de solo lectura en el nuevo Haiku 5.5 y etapas de edición en Sonnet 5.5, cada edición en su propia copia aislada
3. Agrega una regla a CLAUDE.md: cada hallazgo obtiene un agente verificador independiente antes de reportarse, y los bucles de corrección se detienen después de dos rondas sin progreso
4. Enruta forks determinísticos rápidos (elección de herramienta, selección de ruta, reintentos) a través de JEV
Muéstrame cada cambio como un diff primero, sin ediciones hasta que diga go"
https://code.claude.com/docs/en/workflows
