Scrapling está llevando el web scraping en Python a otro nivel.
Han creado una librería open-source capaz de adaptarse automáticamente a cambios en páginas web, evitar bloqueos y ejecutar crawlers completos muchísimo más rápido que BeautifulSoup.
Esto es lo que incluye:
→ Bypass nativo de Cloudflare Turnstile
→ Hasta 774x más rápido que BeautifulSoup
→ Crawling concurrente y multi-sesión
→ Rotación automática de proxies y checkpoints
→ Integración con IA y soporte MCP
No es solo un parser.
Es un framework completo para scraping, automatización y recolección de datos en una sola librería.
Acumula más de 52.2k stars en GitHub, es gratis y 100% open-source.

Hermanos que se dedican a scraping y automatización, atención: hay una cosa llamada Stealth Browser MCP, un navegador sigiloso diseñado específicamente para AI Agents.
¿Cuál era lo más molesto antes? Las verificaciones de Cloudflare, los diversos detectores anti-scraping, las paredes de login, todo eso te bloquea de un plumazo. Esta herramienta abre directamente el núcleo real de Chrome y se mete a la fuerza; en las pruebas, pasa incluso las verificaciones de Cloudflare y Queue-It de ese tipo de colas (por supuesto, depende del sitio, la región y la versión, no garantiza el 100%).
Y no es puro humo: 97 herramientas, desde navegación básica hasta ejecutar comandos CDP directamente, clonar elementos de página, capturar solicitudes de red, todo incluido; si son demasiadas, puedes recortarlas a una versión simplificada de 20.
Los que quieran aprovechar gratis, que vayan y desentrañen el código ellos mismos.
https://github.com/vibheksoni/stealth-browser-mcp





La API de recolección de pago se cobra por mes, estos 8 repositorios en GitHub extienden las mismas funciones a la vista.

Guarda esto primero. Lee los términos del sitio tú mismo, no lo uses para forzar el inicio de sesión.

1. Firecrawl  
Tira una URL, recorre todo el sitio, recoge texto limpio que el modelo pueda digerir. También maneja páginas con JS.  
https://github.com/mendableai/firecrawl

2. Crawl4AI  
Recolección web de texto que los LLM pueden leer directamente. El autor se hartó de las interfaces que cobran por uso y escribió esto.  
https://github.com/unclecode/crawl4ai

3. browser-use  
Usa un agente como si fuera una persona con el navegador: haz clic, llena formularios, sigue procesos. Hecho por el equipo de Zúrich.  
https://github.com/browser-use/browser-use

4. Crawlee  
Rotación de proxies, reintentos de fallos, colas, todo un conjunto base para recolección.  
https://github.com/apify/crawlee

5. Scrapy  
El clásico framework de Python. Para volúmenes grandes, estable, gratis. Del tipo que ha comido durante diez años.  
https://github.com/scrapy/scrapy

6. Scrapling  
Si la página cambia de versión, los selectores aún la encuentran. Menos reescritura de scripts por cambios de estructura.  
https://github.com/D4Vinci/Scrapling

7. AutoScraper  
Dale un ejemplo, aprende la estructura y extrae campos similares.  
https://github.com/alirezamika/autoscraper

8. curl-impersonate  
El handshake de la solicitud se ve como el de un navegador. Úsalo para depuración legítima y tu propio sitio, no como manual para saltar firewalls.  
https://github.com/lwthiker/curl-impersonate
